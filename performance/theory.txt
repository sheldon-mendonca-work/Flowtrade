JVM Flags

Instead of randomly copying internet flags,

we'll understand every one.

For example

-Xms

Why?

Startup latency.

-Xmx

Heap limit.

-XX:+UseG1GC

Low pause collector.

-XX:+UseZGC

Ultra-low latency.

-XX:MaxGCPauseMillis=50

A hint, not a guarantee.

-XX:+HeapDumpOnOutOfMemoryError

Production essential.

-XX:HeapDumpPath

Where to store dumps.

-Xlog:gc*

GC logging.

-XX:+UnlockDiagnosticVMOptions

Diagnostic features.

-XX:StartFlightRecording

JFR.

-XX:FlightRecorderOptions

JFR tuning.

-XX:NativeMemoryTracking=summary

Native memory debugging.

-XX:+AlwaysPreTouch

Useful for predictable latency.

-XX:+UseContainerSupport

Containers.

-XX:MaxRAMPercentage

Container memory.

-Djdk.tracePinnedThreads

Virtual thread debugging.

-Djdk.virtualThreadScheduler.parallelism

Carrier thread tuning.


-----------------------------------------------------------------------------------------

Instead of just Docker + Grafana, you should become comfortable with the JVM's native diagnostics.

Category	Tool	Why It Matters
JVM Profiling	JFR (Java Flight Recorder)	Low-overhead production diagnostics
Analysis	Java Mission Control (JMC)	Analyze JFR recordings
CPU/Allocations	async-profiler	Flame graphs, allocation hotspots, lock contention
Thread Inspection	jstack	Deadlocks, blocked threads, virtual thread issues
Heap Analysis	jmap + Eclipse MAT	Memory leaks and retained objects
Live Monitoring	jcmd	Swiss-army knife for JVMs (GC, JFR, VM info, threads)
Metrics	Micrometer + Prometheus	Application and JVM metrics
Tracing	OpenTelemetry + Jaeger	End-to-end request flow
Logging	Structured JSON logs	Correlate with traces and metrics
Benchmarking	JMH	Correct Java microbenchmarks
Load Testing	k6	Validate latency and throughput under load

A Rule I Want for This Project

Whenever we introduce a new technology, we'll answer these questions before writing code:

What problem does it solve?
Why wasn't the previous solution enough?
What are the trade-offs?
What happens if it fails?
How do I debug it in production?
How do I explain this in an interview?

If we can't answer those six questions, we don't add it yet.
